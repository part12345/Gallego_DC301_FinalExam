# JobTrack - VueJS SPA CRUD Application

A Vue 3 + Vue Router Single Page Application for tracking job applications.

## Assignment Coverage

- Landing page: Welcome
- Authentication: Register and Login
- SPA navigation with Vue Router
- Dashboard page
- Applications page
- Calendar page
- Profile page
- Settings page
- Requirements / CRUD Guide page
- CRUD for job applications: Create, Read, Update, Delete
- Search and filtering
- Responsive mobile-app style UI
- Browser localStorage for simple data persistence

## Main CRUD Flow

1. Create an account from the landing page.
2. Login and open the Dashboard.
3. Go to Applications and press `+` to create a job application.
4. Open an application to read its details.
5. Press Edit to update the application.
6. Press Delete and confirm to remove it.

## Run the Project

```bash
npm install
npm run dev
```

Then open the Vite URL shown in the terminal, normally `http://localhost:5173/`.

## Production Build

```bash
npm run build
```
